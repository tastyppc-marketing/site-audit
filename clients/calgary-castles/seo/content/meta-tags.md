### Sierra Interactive Platform Notes

Sierra Interactive CMS allows meta title and description editing per page:
1. **Pages > Edit Page > SEO Settings** -- update title tag and meta description fields
2. **Blog > Edit Post > SEO** -- update blog post meta fields
3. Community pages may use the **Community Editor** with separate SEO fields
4. Changes take effect immediately; Cloudflare cache may need purging (Settings > Cache > Purge)
5. OG tags: Sierra auto-generates og:image but does NOT auto-set og:title or og:description. These must be added via custom code injection if the platform does not offer dedicated OG fields.

### OG Tag Recommendations

Every page should include these Open Graph tags matching the new meta:

```html
<meta property="og:title" content="[New Title]">
<meta property="og:description" content="[New Description]">
<meta property="og:type" content="website">
<meta property="og:url" content="https://www.sellingcalgarycastles.com/[path]">
<meta property="og:image" content="[page-specific or default hero image]">
<meta property="og:site_name" content="Calgary Castles Team | CIR Realty">
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="[New Title]">
<meta name="twitter:description" content="[New Description]">
```

Currently only 4 of 36 pages (blog posts) have full OG tags. All 36 need them.
