## Critical Structural Notes for New Clients

1. **`competitorComparison[]` uses hardcoded domain-slug column keys** — not `comp1`, `comp2`. The exact keys (`justinhavre`, `calgaryhousefinder`, `kirbycox`, `reevesrealty`, `jdrealestate`, `karenfawcett`) must match what the report template expects. For a new client's market, these keys will be different competitor domain slugs.

2. **`rankHistory.keywords` is an object keyed by keyword string**, not an array. Each keyword has `volume`, `difficulty`, optional `note`, and a `history` object keyed by domain → date → rank.

3. **`siteComparison[]` uses numeric `client` value but string competitor columns** — wait, actually `client` is a number (36), while `competitorComparison[]` uses all strings including client. These are two different structures for two different report sections.

4. **`contentQuality.pages[].readabilityScore` doubles as `fleschReadingEase`** — both fields are the same value. The `readabilityScore` at the page level is a convenience copy.

5. **`localSeo.serviceAreaMap` is GeoJSON** — it contains a FeatureCollection with both a Point (client location) and a Polygon (service area boundary). The polygon coordinates are `[lng, lat]` order (GeoJSON standard).

6. **`pillars[].title` and `pillars[].desc` use literal `\n` for line breaks** — these are intentional and used by the report renderer to create multi-line display.

7. **`quickWins[]` (top-level) is a simplified version of `actionPlan.quickWins[]`** — the top-level version only has `action` and `impact`. Do not confuse the two.

8. **`competitorAnalysis.organicKeywordsComparison` is a freeform object**, not an array. It has domain strings as keys plus a `"note"` key. This is an irregular structure.
