# Data Contract Map — Multipage Report System

Generated by research agent on 2026-04-08.
Source files read: `generate-multipage-report.js` and all `pages/*.js` in
`/mnt/c/dev/site audit/template/reports/multipage/`.

---

## How the System Works

1. `audit-data.json` is the canonical data source.
2. `generate-multipage-report.js` reads it, runs `normalizeAuditData()`, then
   injects the result as `window.AUDIT_DATA` into every HTML page at build time.
3. Each `pages/*.js` renderer reads `window.TPPC.data` (aliased from
   `window.AUDIT_DATA`) and writes HTML into DOM containers.

The generator fills gaps automatically from sibling research files when fields
are missing. Those auto-populations are documented in the "Generator
Auto-Populations" section at the end.

## Generator Auto-Populations (normalizeAuditData)

These fields are filled in automatically by the generator if absent from
`audit-data.json`. Understanding them prevents duplication and debugging
confusion.

| Target field | Source used | Condition |
|---|---|---|
| `data.coreWebVitals` | `data.technicalSeo.coreWebVitals` | Only if `data.coreWebVitals` is missing |
| `data.coreWebVitals.[mobile|desktop].score` | `.performanceScore` on same object | Copied if `score` is null |
| `data.technicalSeo.lighthouseResults` (array) | Normalized from `lighthouseResults.clientPages` dict format | If `lighthouseResults` is not already an array |
| `data.technicalSeo.lighthouseResults` (array) | `research/pagespeed-data.json` | If array is empty after dict check |
| `data.pageSpeedComparison` | `data.competitorAnalysis.pageSpeedComparison` or `data.technicalSeo.pageSpeedComparison` | Prefers `competitorAnalysis` version when `technicalSeo` version has all-identical scores (stale detection) |
| `data.pageSpeedComparison[].name` and `.score` | Derived from `{domain, mobileScore, desktopScore}` | If entries use domain-keyed format instead of `{name, score}` |
| `data.technicalSeo.pageAudits` | `research/crawl-data.json` | If `pageAudits` is empty or missing |
| `data.internalLinking.total_pages`, `total_internal_links`, `avg_inbound_links`, `avg_outbound_links`, `orphan_count`, `orphan_rate`, `orphans[]` | `research/link-graph.json` | If `total_pages` is 0 or missing |
| `data.internalLinking.hubClusters` | `research/link-graph.json` | If `hubClusters` is empty |
| `data.contentQuality.pages[].readability.syllablesPerWord` | `research/page-text-analysis.json` | Per-page enrichment if field is null |
| `data.backlinks.topBacklinks` | `research/client-backlinks.json` | If file has more entries than current array |
| `data.backlinks.topReferringDomains` | `research/client-backlinks.json` | If `topReferringDomains` is missing |
| `data.domainMetrics` | `data.backlinks.competitorDomainMetrics`, `data.competitorAnalysis.domainMetricsComparison`, or `research/domain-metrics.json` | If `data.domainMetrics` is missing or empty |
| `data.backlinkOpportunities.client` | `data.backlinks.domainMetrics` | If `bo.client` is missing |
| `data.backlinkOpportunities.competitors` | `data.backlinks.competitorDomainMetrics` | If `bo.competitors` is missing |
