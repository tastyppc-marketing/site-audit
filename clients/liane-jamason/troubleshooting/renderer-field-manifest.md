### renderKeywordTable(data)
**DOM target:** `#rankings-content`

| Field | Type | Notes |
|-------|------|-------|
| `data.keywords` | array | Must be an array; filtered for falsy entries |
| `data.keywords[].keyword` | string | Keyword text |
| `data.keywords[].volume` | string/number | Monthly volume; `parseNumber()` strips `$,%,` chars |
| `data.keywords[].clientRank` | string/number | Rank cell + CSS class; `parseRankNumber()` extracts first digit sequence |
| `data.keywords[].competitorRank` | string/number | Competitor rank cell |
| `data.keywords[].topResult` | string | Top result URL; `max-width: 280px` truncation |
| `data.keywords[].difficulty` | string/number | Optional — appended as `(D: X)` if present |
| `data.keywords[].cpc` | string/number | Optional — formatted as currency if present |

**Stat cards computed from array:**
- Top 10 count: keywords where parsed rank ≤ 10
- Top 30 count: keywords where parsed rank ≤ 30
- Not ranking count: keywords where rank is NaN

**Conditionals:**
- Empty state rendered if `!keywords.length`
- `difficulty` and `cpc` only rendered if `hasValue()` returns true

- Bar colors: rank-green → rgba(34,197,94), rank-orange → rgba(249,115,22), other → rgba(239,68,68)

**Conditionals:**
- Empty state if no keywords have parseable numeric volume

## Type Requirements for Chart.js Fields

These fields cause silent breakage or JS errors if wrong type:

| Field | Required type | What breaks if wrong |
|-------|--------------|---------------------|
| `keywords[].volume` | parseable number | Bar omitted from chart |
| `siteComparison[].client` | parseable number OR text | Row excluded from radar/gap chart |
| `pageSpeedComparison[].score` | finite number via `Number()` | Entire chart empty state |
| `rankHistory.keywords[kw].history[domain][date]` | number or null | Null-safe; non-number treated as not ranking |
| `coreWebVitals.mobile.score` | number (0-1 or 0-100) | normalizeScore() handles both |
| `technicalSeo.lighthouseResults[].performanceScore` | number (0-1 or 0-100) | normalizeScore() handles both |
| `technicalSeo.crawlIssues[].statusCode` | number | statusBadge() uses toNumber() |
| `backlinkOpportunities.opportunities[].score` | 0-100 number | Used as CSS `width:%` — must be 0-100 |
| `backlinkOpportunities.competitors[].referringDomains` | number | Log scale chart — zero causes log(0) → handled as 0 |
| `localSeo.businessProfile.latitude` | number | Map center — string will work via Leaflet coercion |
| `localSeo.businessProfile.longitude` | number | Same |
