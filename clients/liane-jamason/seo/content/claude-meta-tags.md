## Implementation Notes

### 1. How to Implement in Rank Math SEO Plugin

In the WordPress admin, navigate to each page or post and scroll to the Rank Math SEO meta box below the editor. Click "Edit Snippet" to open the title and description fields. Paste the new title into the "SEO Title" field and the new description into the "SEO Description" field — do not use Rank Math's variable syntax (like `%title% %sep% %sitename%`), as these optimized tags are hand-written to exact character counts. Click "Update" or "Publish" to save. For bulk edits, Rank Math Pro's "Content AI" or the built-in spreadsheet-style editor under Rank Math > Titles & Meta can speed up the process, but verify each entry individually after bulk import.

### 2. Character Count Verification

Before saving each entry, verify character counts using a tool like [charactercounttool.com](https://charactercounttool.com) or the SERP preview built into Rank Math. Google may truncate titles beyond ~60 characters and descriptions beyond ~155 characters on desktop (less on mobile). The counts in this document were measured manually — double-check any entry that looks close to the limit before publishing.

The Travel Draft and Credit Card Points pages are completely unrelated to St. Petersburg real estate and dilute the site's topical authority. In Rank Math, navigate to each page, open the "Advanced" tab in the Rank Math meta box, and set the "Robots Meta" to **noindex**. This tells Google to drop these pages from its index without deleting them from the site. Alternatively, if Liane wants to keep them visible to visitors who find them directly, leave them published but noindexed — they will still be accessible via direct link or site navigation but won't compete with real estate pages in search.
