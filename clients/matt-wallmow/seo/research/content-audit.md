# Content Audit: mattwallmow.com
**Client:** Matt Wallmow / Wallmow Realty, Inc / Lakeland Realty
**Location:** Rhinelander, WI (Northwoods Wisconsin)
**Audit Date:** April 15, 2026
**Auditor:** Site Audit Platform (Automated + Manual Review)

---

## Executive Summary

**Overall Content Grade: B-**

mattwallmow.com is built on the AgentFire platform and presents a modern, visually appealing real estate website with strong branding. The site contains a mix of well-written service pages, a growing blog with genuinely useful local content, and several structural/content gaps that limit its SEO ceiling.

**Strengths:**
- Recent blog posts (March-April 2026) are high-quality, locally relevant, and well-structured for SEO
- About page bio is detailed, data-driven, and establishes strong E-E-A-T signals
- Good use of testimonials across multiple pages for social proof
- Clear service area identification (Northwoods Wisconsin communities)

**Weaknesses:**
- Multiple meta descriptions are missing or generic template text
- H1 tags on core pages are vague single words ("Confidence," "Dream Home," "Real Estate") rather than keyword-rich
- Communities page has incomplete data for 4 of 7 counties (Lincoln, Oneida, Price, Vilas show blank fields)
- South Florida section on homepage creates geographic confusion for local SEO
- Identical testimonials duplicated across 4+ pages dilute perceived uniqueness
- Several nav links point to 404 pages (exclusive-listings, certain blog slugs)
- Contact page has no meta description
- Blog has only 10 posts total; 4 of the older ones appear to be generic/template content
- No dedicated Rhinelander-focused landing page despite it being a primary service area

## Sitewide Content Issues

### 1. Meta Description Crisis
**6 of 11 major pages have NO meta description at all.** 2 additional pages have placeholder-quality descriptions ("This is how we help buyers"). Only the homepage has a properly written meta description.

| Page | Meta Description Status |
|------|----------------------|
| Homepage | Good (but too long at 256 chars) |
| About | Template boilerplate |
| Buyers | Placeholder ("This is how we help buyers") |
| Sellers | Placeholder ("This is how we sell properties") |
| Communities | MISSING |
| Contact | MISSING |
| Blog | MISSING |
| Recently Sold | MISSING |
| Testimonials | MISSING |
| Blog Posts | MISSING (ogDescription set instead) |

### 2. H1 Tag Quality
Most core page H1 tags are single vague words with no SEO value:

| Page | Current H1 | Recommended H1 |
|------|-----------|----------------|
| Homepage | "Real Estate Professional" | "Northwoods Wisconsin Real Estate -- Rhinelander & Minocqua" |
| About | "Northwoods Guide" | "About Matt Wallmow -- Your Northwoods Real Estate Expert" |
| Buyers | "Dream Home" | "Buy a Home in the Northwoods -- Rhinelander, Minocqua & Beyond" |
| Sellers | "Confidence" | "Sell Your Northwoods Home -- Expert Listing Services" |
| Communities | "Communities" | "Northwoods Wisconsin Communities -- Find Your Perfect Area" |
| Contact | "Real Estate" | "Contact Matt Wallmow -- Northwoods Real Estate Agent" |
| Blog | "Northwoods" | "Northwoods Real Estate Blog -- Market Updates & Local Insights" |

### 3. Broken/404 Pages
- /exclusive-listings/ returns 404
- Several blog post URL guesses returned 404, suggesting inconsistent slug patterns
- Community sub-pages (/communities/oneida-county/, /communities/vilas-county/) timed out

### 4. WordPress Editor Artifact
Blog posts contain a stray `<h1>Insert/edit link</h1>` element -- a WordPress/AgentFire editor dialog leaking into the rendered HTML. Appears on at least 3 blog posts.

### 5. Duplicate Content Across Pages
The same 4 testimonials (Andrew Scherer, Dan Morris, Mike Klingelhoets, Ron Gagnier) appear identically on:
- Homepage
- Buyers page
- Sellers page
- Testimonials page

This creates a perception of thin, repetitive content and wastes unique content opportunities.

### 6. South Florida Geographic Confusion
The homepage contains an entire section about South Florida communities (Fort Lauderdale, Davie, Boca Raton, Aventura, Sunny Isles Beach, Bal Harbour, Miami). This is devastating for local SEO signals. If Matt serves both markets, these need to be on separate landing pages or a subdomain -- not mixed into the Northwoods homepage.

### 7. Counter/Stats Animation Failure
Multiple pages show "0" for statistics that should display impressive numbers. The JavaScript counter animation likely fails for users with slow connections, disabled JS, or certain browsers. Consider using static fallback values.
