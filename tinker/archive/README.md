# archive/

Things that were removed from active use but are kept around for history.

The project rule is **no deletions** — if something needs to leave the working
set, it gets moved here instead. That preserves the audit trail and means a
discarded idea can always be revived without `git log` archaeology.

## What's in here

- **`scaffold_test/`** — output of a one-time verification run of
  `tinker.py new scaffold_test`. Kept as a reference for what a freshly
  scaffolded experiment looks like before anyone has touched it.
