tinker

A sandbox of tiny, single-file code experiments — generative art, small games, useful CLIs. Stdlib-only Python. No frameworks. No build step.

9 experiments 43 tests 0 dependencies

Getting started

One runner, nine ideas

git clone https://github.com/tastyppc-marketing/site-audit
cd site-audit/tinker
python3 tinker.py list                   # see what's in the box
python3 tinker.py run dice 3d6+2         # roll dice
python3 tinker.py run maze 20 10         # generate a maze
python3 tinker.py new yourthing          # scaffold a new experiment
python3 tinker.py test                   # run the full test suite

Philosophy

Each experiment is the smallest thing that demonstrates an idea. Pure stdlib. Importable functions, so it can be tested. One folder, one .py, one README.md. If you reach for a framework, you've left the spirit of the repo.
